# Daily Logs

Use this folder to record daily co op work.

Each daily log should include:

| Field | Meaning |
| --- | --- |
| Date | Work date |
| Main work | Main tasks |
| Problem | Problem or goal |
| Action | What I did |
| Tools | Tools or tech used |
| Result | What changed |
| Resume value | Possible resume value |
| Next step | Follow up work |
